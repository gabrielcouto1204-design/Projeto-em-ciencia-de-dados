# Dados

## Organização

- `raw/`: arquivos originais das fontes, quando a redistribuição for permitida.
- `processed/`: dados tratados e padronizados para análise.

Não versionar dados pessoais, confidenciais ou arquivos grandes sem verificar as condições de uso da fonte.

## Catálogo esperado

Para cada base utilizada, documentar em `docs/fontes_dados.md`:

- instituição responsável;
- nome da base;
- URL oficial;
- período de referência;
- data de acesso;
- unidade de análise;
- variáveis relevantes;
- limitações e mudanças metodológicas;
- transformações aplicadas.
