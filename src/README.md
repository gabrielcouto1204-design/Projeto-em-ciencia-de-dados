# Código-fonte

Esta pasta concentrará o código reutilizável do projeto, organizado futuramente por responsabilidade, por exemplo:

- `ingestion/`: aquisição e leitura das fontes;
- `cleaning/`: limpeza e padronização;
- `analysis/`: métricas e análises;
- `visualization/`: componentes compartilhados de visualização.

A implementação deve privilegiar funções pequenas, testáveis e documentadas.
