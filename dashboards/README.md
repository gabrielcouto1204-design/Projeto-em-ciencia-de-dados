# Dashboard

A aplicação interativa do Educadata será organizada nesta pasta.

## Requisitos funcionais previstos

- filtros por ano e território;
- indicadores resumidos de abandono/evasão;
- séries temporais;
- comparações entre grupos e territórios;
- visualizações de fatores associados;
- indicação clara da fonte e do período de cada indicador;
- mensagens de alerta para ausência ou baixa cobertura de dados.
